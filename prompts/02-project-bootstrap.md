# Project Bootstrap

## Goal

Understand the challenge requirements, identify the minimum viable scope, and create a realistic implementation plan before starting development.

## Prompt

I am a React developer with no previous Angular experience.

Please help me:

- summarize the challenge requirements
- identify the mandatory features
- separate mandatory requirements from optional improvements
- explain the Angular concepts I need to learn first
- propose a realistic implementation plan for a short delivery timeline

## Accepted

- A breakdown of the challenge requirements.
- A distinction between mandatory and optional features.
- An Angular learning roadmap focused on the concepts required to complete the challenge.
- A phased implementation plan prioritizing required functionality before optional improvements.
- A recommendation to focus on delivering a working solution before investing time in additional features.

## Discarded

- Optional features that were not required by the challenge.
- Improvements that could compromise the delivery timeline.
- Ideas that introduced unnecessary complexity for a first Angular project.

## Modified

- Adapted the implementation plan to fit the available time.
- Prioritized learning only the Angular concepts required to complete the challenge instead of attempting to learn the framework in depth before starting development.
- Used the generated roadmap as a guide while validating decisions throughout the project.

## Outcome

As this was my first Angular project, the main challenge was understanding the requirements correctly and determining what was truly necessary to deliver within the available time.

This session helped transform the challenge into a structured plan with clear priorities, reducing uncertainty before development began.

The resulting roadmap became the foundation for the architectural, implementation, testing, and documentation decisions made throughout the project.
